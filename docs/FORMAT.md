# RVC1 scene chunk wire format

Status: experimental format 1. The format is little endian, byte-aligned, and independent of native Zig aggregate layout. All offsets and lengths are unsigned 32-bit quantities measured in bytes. A file is exactly its declared length, at most `2^32 - 1` bytes. The encoder and view do not use native struct casts.

## Header (32 bytes)

| Offset | Size | Name | Rule |
|---:|---:|---|---|
| 0 | 4 | magic | ASCII `RVC1` |
| 4 | 2 | version | 1 |
| 6 | 2 | header size | 32 |
| 8 | 4 | node count | N |
| 12 | 4 | node offset | 32 |
| 16 | 4 | label blob offset | 32 + 24N (checked) |
| 20 | 4 | label blob length | total length - label blob offset |
| 24 | 4 | total byte length | equals supplied byte slice length |
| 28 | 4 | reserved | zero |

## Node record (24 bytes)

| Offset | Size | Name | Rule |
|---:|---:|---|---|
| 0 | 4 | id | u32; not necessarily unique |
| 4 | 4 | x | IEEE-754 binary32, finite |
| 8 | 4 | y | IEEE-754 binary32, finite |
| 12 | 4 | z | IEEE-754 binary32, finite |
| 16 | 4 | label offset | relative to label blob base |
| 20 | 4 | label length | contained in label blob |

Nodes are stored consecutively followed immediately by the label blob. Labels are byte strings, may be empty or overlap, and need not be UTF-8 or null-terminated. Offset zero is valid. No object graph, native pointer, checksum, compression, authentication or mutable schema evolution is implied. An independent fixture is in `src/binary/fixtures/two_nodes.rvc` and generated by `scripts/reference_checks.py`.

`WorldChunk.View.open` checks header, arithmetic, canonical table/label extent, every node's finite position and label extent. It takes O(N) time, O(1) extra space, and does not allocate. Scalar values are decoded on access; label bytes are borrowed directly. This is zero-copy access to backing bytes, not zero instructions, nor a claim that the OS never copies pages.

## Mapping integration

Pass a read-only mapping's byte slice to `View.open`, keep the mapping and immutable file alive until the last view and label slice is dropped, then unmap it. Use an application-level file lease/immutable file policy; `[]const u8` does not make a writable alias or concurrent file truncation safe. `View` is not a mapping owner. Mapping APIs, file authentication and resource admission limits belong to a future platform layer. For untrusted input cap file size/node count before loading, and isolate external storage where appropriate.
